# AI Council — Catálogo editable

Sube los archivos de este ZIP a la raíz de tu repositorio GitHub y activa GitHub Pages (Settings → Pages → Deploy from a branch → main → /(root)).

En **Catálogo** puedes agregar, editar y eliminar asistentes: nombre, proveedor, URL web, rol, icono e instrucciones. Incluye ejemplos iniciales editables, pero no hay una lista cerrada. Puedes registrar cualquier asistente que tenga una interfaz web.

Modo híbrido: no utiliza API Keys. El usuario abre el sitio externo, copia el prompt y pega la respuesta. No existe comunicación automática con el proveedor. Los datos se guardan localmente en el navegador.
